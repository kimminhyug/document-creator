# 반복 검증 보고서

기록일: 2026-09-16 KST

## 대상과 방법

생성기와 별개로 상위 경로의 `_test_product`에 로그인·대시보드·설비 목록·상세·CSV/Excel 다운로드·PostgreSQL을 가진 가상 제품을 구성했다. 실제 운영 데이터나 회사 계정은 사용하지 않았다. 테스트 제품과 실행 결과는 생성기 Git 저장소에 포함하지 않는다.

사용자 매뉴얼·기능·API·지표 계산식·테이블 명세를 분류된 Markdown으로 작성하고 4형식으로 생성했다. 일반 사용자, 개발자, 데이터 담당 독립 에이전트가 원문과 출력을 읽었다. 각 회차를 마감한 뒤 결함을 수정하고 동일한 전체 범위를 다시 실행했다. 첫 실패 기록과 검사 도구 자체의 오류도 보존했다.

## 수정과 회귀 검증

| 범위 | 수정 | 확인 |

| 캡처 | SPA 같은 경로 탐색, 인증 저장소 보존, 안전한 실패 단계 | 실제 Chromium 로그인·캡처·실패 경로 |
| Markdown | 내용 컨테이너, 중첩 제목, 코드 펜스, 내부 참조 | 원문 전행 및 출력 본문 대조 |

## 4차 실행 결과

- Python 3.12.14 단위·통합 57개 통과, skipped 0.
- 5종 × 4형식 = 20개 출력. 공개 Markdown 32개와 문서 인덱스 JSON 5개 검토.
- PDF 68쪽, HTML 51화면 전수 독립 시각 검토. PDF 본문 1,460개 블록 대조 통과.
- 일반 사용자 고유 UI 137개 통과. 개발자 API 156개·UI 38개 통과. 데이터 독자 DB·API 추가 검증 127개 통과. 이 집계들은 범위가 겹치므로 합산한 고유 사례 수로 제시하지 않는다.
- 부모 검증: 캡처 33, 엔진 시나리오 12, workflow 게이트 42, 세션 경계 4, 계정 전환 1, DB 시간 제한 1, DB 중단·복구 8, 추가 DB 경계 10개 통과.
- 추가 UI: 36개 정상 조합, 모바일 상세 가로 스크롤 4개, 키보드 8개, 상태·지연 응답 72개 통과. 날짜 입력의 모든 운영체제별 세그먼트 편집 방식까지 확인한 것은 아니다.

원시 API 검사에 남은 BLOCKED는 독립 검토 또는 추가 실행으로 근거를 확보한 범위만 보완한다. 전체 407행의 최종 판정은 별도 테스트 제품의 `validation/round-04/case-ledger.json`과 `round-summary.md`를 따른다. 자동 테스트 결과만으로 전체 문서를 승인하지 않는다.

## 미검증과 보안 경계

- Word·Excel 전체 본문·셀·링크 구조를 확인했지만 실제 앱 화면 검수는 환경 부재로 보류했다. PDF·HTML 성공으로 대체하지 않았다.
- 실제 회사 서식과 운영 제품의 인증·업무 사실, 외부 유료 AI 공급자는 별도 검증해야 한다.
- 실제 조사 단계와 독립 공개 문서 검토 기록을 구분한다. 자동 테스트의 게이트 성공을 실제 문서의 승인으로 복사하지 않는다.
- 커밋 전 staged 파일의 비밀 패턴과 비공개·생성 경로를 검사한다. 실제 로컬 테스트 비밀번호는 출력 문서의 압축 내부까지 별도로 검색한다. 이 검사는 알려진 패턴·테스트 비밀번호 범위이며 모든 종류의 민감정보 부재를 보증하지 않는다.

## 재검증 자료 위치

테스트 제품의 `tools/`에 실행 도구, `authoring/`에 작성 원본, `generator-runs/round-04/`에 고정 엔진·수집·생성 결과, `validation/round-04/`에 역할별 보고와 원시 결과를 보존한다. 비공개 연결 정보는 `.local/`에 둔다. 생성기 저장소에는 코드·정책·회귀 테스트와 이 요약만 보관한다.

## 최종 장부 판정

4차 고정 사례 407행은 PASS 273 / FAIL 0 / BLOCKED 116 / N/A 18로 마감했다. 보류에는 Word·Excel 실제 화면, 일반 사용자의 실제 다운로드 목록·Office 열기, 제공되지 않은 일부 로딩·해상도별 상태 조합이 포함된다. 따라서 제품·문서 묶음의 최종 승인은 보류한다. 추가 UI 108장 전수 시각 검토에서 신규 결함은 없었다.

실제 워크플로는 조사·개요·초안까지 8단계를 공식 명령으로 진행했다. 공개 원본과 고정 엔진 341파일 해시 불변을 확인했다. 사실검증·독립 검토·스타일·전달 게이트를 완료한 것으로 꾸미지 않았다. 세션은 별도 실제 프로세스 재시작 후 이전 쿠키가 401이 되는 시험도 추가 통과했다.
