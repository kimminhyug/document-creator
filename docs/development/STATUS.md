## 검증

최종 테스트 결과는 아래 마지막 검증 기록을 따른다. 테스트 실행에는 실제 로컬 Chromium 캡처가 포함되며 실제 제품의 인증을 사용하지 않는다.

- Python 3.12 환경 진단: Python 출력 라이브러리 및 사용 도구 경로 확인.
- 실제 캡처: 별도 프로세스 병렬 분배, 긴 화면 분할·마스킹, 로그인, dark/en-US/640×480, API 대기/Timeout, 자격 증명 미출력.
- AI 실행: 로컬 테스트 프로세스의 실행·실패·잘못된 응답·누락 환경·Timeout·다른 담당 파일 변경 거부. 유료 AI 서비스는 호출하지 않음.
- 문서: HTML 이스케이프/CSP, Excel 수식 문자열 비실행, Word 스타일/XML, 로컬 이미지 임베딩, 내부 출처 번호 비출력.
- 4형식 실제 출력: output/documents/demo/demo/20260915T155349Z-dcf55364/table-spec-index-20260915T155401Z-65b98f23/.
- 해당 PDF 7쪽 전체를 이미지로 확인. 표지·저작권·목차·반복 표 헤더·머릿글·바닥글·마지막 페이지에 잘림/겹침 없음.
- 해당 HTML을 Chromium 1200×900에서 확인. 표 4개, 가로 넘침 없음, 스크립트 없음.
- 예제는 가상 사실이며 workflow의 조사·검토 단계가 자동 승인된 결과가 아님.

## 환경이 있어야 검증 가능한 부분

- 실제 PostgreSQL 접속·서버 권한/함수/승인 View 검증: 접속정보가 없어 미검증.
- 실제 제품의 로그인·selector·API 계약: 로컬 테스트 외 미검증.
- Word/Excel 앱 화면 검수: 구조 검증은 통과했지만 해당 앱에서의 페이지/시트 화면은 미검증. PDF/HTML 검수로 대체하지 않음.
- 회사 실제 서식/로고/저작권 문구: 제공된 공식 양식이 없어 예제 기본값만 구현.
- 공급자 CLI/API 실행은 회사 래퍼를 설정해야 함. 특정 모델을 임의 연결하거나 비용을 발생시키지 않음.

## 지원 범위의 경계

전체 GFM/수식 렌더링, 복잡한 병합 셀, 회사 원본 DOCX의 스타일 자동 추출, 이미지 배경/워터마크, 자동 페이지 번호 목차는 현재 지원하지 않는다. 문서 계약 검사는 필수 절·표·출처 연결·상태 검사이며 업무 사실의 진위는 독립 검토한다.

운영자 ID와 파일 소유권 감사는 OS 보안 격리나 인증된 전자 승인 시스템이 아니다. 로컬 실행기는 승인된 프로그램만 연결한다.
