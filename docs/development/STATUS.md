# 구현 상태와 검증

기록일: 2026-09-16 KST

## 현재 판정

5종 문서의 분류된 Markdown 작성과 Word·Excel·HTML·PDF 생성, 역할별 검토 및 단계별 게이트를 구현했다. 로컬 테스트 제품으로 반복 검증했지만 회사 실제 제품의 인증·업무 사실·공식 양식까지 승인된 상태는 아니다. Word·Excel 실제 앱 화면 검수는 미검증이다.

## 구현 범위

- 정책, 회사·제품 등록, 가상 예제, 실행 결과를 분리하고 폴더별 INDEX로 안내한다.
- Markdown 본문과 관리용 메타데이터를 분리한다. 최종 문서에 내부 근거 번호나 작업 폴더 경로를 출력하지 않는다.
- 조사부터 전달까지 12단계, 역할별 담당 파일, 조사 대상 추가, 변경 시 재검토, 승인되지 않은 전달 차단을 지원한다.
- 표지·저작권·목차·머릿글·바닥글·끝 페이지와 제목·본문·표의 폰트, 크기, 굵기, 색, 여백을 설정한다.
- Playwright 프로세스 병렬 분배, 테마·언어·해상도·로그인·API 대기·타임아웃·마스킹·파일 분류를 지원한다.
- PostgreSQL은 승인된 구조화 SELECT, 읽기 전용 트랜잭션, 권한 검사, 시간·행 제한으로 수집한다.
- AI 실행 연결은 기본 dry-run이며 회사가 승인한 로컬 명령을 설정한다. 특정 유료 공급자를 자동 호출하지 않는다.

## 반복 검증에서 수정한 사항

- 로그인 후 같은 SPA 경로를 캡처할 때 인증 저장소를 유지하며 새 탐색을 실행한다. 실패 단계만 안전하게 기록한다.
- Markdown 내용 컨테이너를 출력에서 제거하고 중첩 제목, 백틱·물결표 코드 블록을 처리한다.
- 내부 문서 참조를 읽을 수 있는 문서명·절 이름으로 바꾼다. 외부 링크는 작성자가 명시한 목적지만 연결한다.
- PDF 실제 페이지 번호 목차와 탐색 링크, 짧은 절의 제목·본문 묶음, 긴 표의 열 너비와 줄바꿈을 개선했다.
- PDF 글꼴에 없는 문자는 기존 번들 글꼴의 지원 여부를 확인한다. 둘 다 지원하지 않으면 오류로 알려 빈 문자 출력을 막는다.
- 전수 독해, 회차별 결함 기록 후 수정, 같은 범위 재검증 정책을 명시했다.

## 검증 증거

- Python 3.12.14: 단위·통합 테스트 57개 통과, skipped 0. 실제 Chromium 캡처 포함.
- 별도 테스트 제품: 저장소와 같은 상위 경로의 `_test_product`. 가상 데이터와 로컬 PostgreSQL을 사용한다.
- 4차 검증: 문서 5종 × 출력 4형식 = 20개 생성. 독립 역할별 원문 전행 검토, PDF 68쪽·HTML 51화면 전수 시각 검토, PDF 본문 1,460개 블록 대조 완료.
- 실제 로컬 DB 권한·조회, 서버 중단·복구, 시간 제한, 로그인·세션 경계, 계정 전환, 캡처, workflow 게이트를 실행했다.
- Word·Excel은 전체 본문·셀 추출 및 구조 검증을 수행했다. 이 결과는 앱 시각 검수 통과를 뜻하지 않는다.
- 자세한 범위와 보류 항목은 [반복 검증 보고서](VALIDATION_REPORT.md)를 따른다.

## 남은 제약

- Word·Excel 앱 또는 호환 렌더러가 없어 해당 출력의 실제 페이지·시트 화면 검수는 보류한다. PDF·HTML로 대체하지 않는다.
- 실제 회사 서식·로고·저작권 문구, 운영 제품의 인증과 데이터 계약은 해당 자료로 별도 검증해야 한다.
- 전체 GFM·수식 렌더링, 복잡한 병합 셀, 기존 DOCX 스타일 자동 추출, 이미지 배경·워터마크는 지원하지 않는다. PDF 페이지 번호 목차는 지원한다.
- 운영자 ID와 파일 소유권 기록은 OS 보안 격리나 인증된 전자 승인 시스템이 아니다.
- 로컬 테스트 성공은 모든 가능한 제품·브라우저·데이터 조합에 대한 보증이 아니다. 미검증 사례를 통과로 기록하지 않는다.

## 조사 공통 명령 추가 검증

`document.py research plan/run/status/resume`을 추가했다. 제품·환경 설정을 재사용하며 계획 조회, 새 작업 생성, 미확인 항목 조회, 현재 조사 단계 재실행을 제공한다. 기본 dry-run이고 실제 AI 실행·캡처·읽기 전용 DB 수집은 명시 옵션이 필요하다. 실행 결과로 단계를 자동 승인하지 않는다. 사용법은 [조사 실행 명령](../guides/RESEARCH_COMMANDS.md)을 따른다.

Python 3.12 전체 단위·통합 69개 통과(32.832초, skipped 0). 추가 독립 QA는 임시 저장소의 실제 CLI 및 로컬 모의 실행 23건 통과. 외부 유료 AI·운영 DB는 호출하지 않았다. 이전 57개는 4차 문서 검증 당시의 결과이며 이번 전체 회귀에는 신규 12개가 포함된다.

사용자가 LibreOffice 설치를 승인하여 Windows에 26.8.0.3을 설치했다. 기존 DOCX 5종을 원본 변경 없이 총 87페이지로 렌더링했으며 실제 페이지 검토 중이다. 이 시점에서 Word·Excel 전체 시각 검증이 완료된 것은 아니다. LibreOffice 확인은 Microsoft Word 앱의 확인과 구분한다. 이전의 렌더러 부재 기록은 당시 환경을 설명한다.
