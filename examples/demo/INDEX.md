# 데모 전용 예제

**이 폴더 전체는 가상 테스트용입니다. 실제 회사 정책이나 실제 제품 정보가 아닙니다.**

| 위치 | 용도 |
| --- | --- |
| [companies](companies/INDEX.md) | 가상 회사 문구와 출력 테마 |
| [products](products/INDEX.md) | 로컬 화면·가상 DB 조회·문서별 작업 설정 |
| [content](content/INDEX.md) | 내부 출력 어댑터 검증용 가상 데이터 |
| [tools](tools/INDEX.md) | 로컬 테스트 화면 서버·Markdown 예제 생성 |

전체 공통 작성 규칙은 [rules](../../rules/INDEX.md), 운영 정책은 [docs/policies](../../docs/policies/INDEX.md)에서 관리합니다. 실제 회사·제품 설정은 [config](../../config/INDEX.md)에 등록합니다.

예제를 실행해 생성한 MD/캡처/문서는 workspaces와 output에 별도로 저장되며 이 폴더에 섞이지 않습니다.
